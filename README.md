## 📖 About Me

I am a passionate **Embedded Systems Engineer** focused on bridging the gap between hardware and software. I love low-level architecture, microcontrollers, and bringing physical hardware to life. 

* 🔭 **Current Focus:** Developing firmware for advanced Espressif microcontrollers and designing compact, autonomous hardware systems.
* 🛠️ **Approach:** I emphasize production-grade, modular code, efficient memory management, and clean Git workflows.
* 💬 **Ask me about:** C/C++ pointers, hardware registers, peripheral protocols (I2C, SPI, UART), and custom DIY robotics hardware.
